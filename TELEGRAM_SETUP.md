# Настройка Telegram бота для приема заказов

## Шаг 1: Создание бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Введите имя для бота (например, "Total Lookas Orders")
4. Введите username для бота (должен заканчиваться на "bot", например, "totallookas_orders_bot")
5. BotFather выдаст вам токен вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

## Шаг 2: Получение Chat ID

### Вариант 1: Личные сообщения (для получения заказов лично)

1. Найдите бота [@userinfobot](https://t.me/userinfobot) в Telegram
2. Нажмите "Start"
3. Бот пришлет ваш Chat ID (например, `123456789`)

### Вариант 2: Группа/канал (для получения заказов в группу)

1. Создайте группу в Telegram или используйте существующую
2. Добавьте вашего бота в группу (используйте username бота)
3. Сделайте бота администратором группы
4. Отправьте любое сообщение в группу
5. Откройте в браузере: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
   - Замените `<YOUR_BOT_TOKEN>` на токен из шага 1
6. Найдите в ответе `"chat":{"id":-1001234567890}` - это ваш Chat ID
   - Для групп Chat ID начинается с `-`

## Шаг 3: Настройка переменных окружения

Откройте файл `.env.local` и замените значения:

```env
TELEGRAM_BOT_TOKEN="ваш_токен_от_BotFather"
TELEGRAM_CHAT_ID="ваш_chat_id"
```

Пример:
```env
TELEGRAM_BOT_TOKEN="1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
TELEGRAM_CHAT_ID="123456789"
```

Или для группы:
```env
TELEGRAM_BOT_TOKEN="1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
TELEGRAM_CHAT_ID="-1001234567890"
```

## Шаг 4: Перезапуск сервера

После изменения `.env.local` перезапустите сервер разработки:

```bash
# Остановите текущий процесс (Ctrl+C)
npm run dev
```

## Шаг 5: Тестирование

1. Откройте страницу товара на сайте
2. Нажмите кнопку "Заказать"
3. Заполните форму и отправьте
4. Проверьте Telegram - должно прийти сообщение с заказом

## Формат сообщения в Telegram

```
🛒 Новый заказ!

📦 Товар: Название товара
📊 Количество: 100 шт
👤 Имя: Иван Иванов
📱 Телефон: +7 (999) 999-99-99

⏰ Дата: 19.11.2025, 15:30:45
```

## Для деплоя на Vercel

Добавьте переменные окружения в настройках проекта Vercel:

1. Зайдите в dashboard.vercel.com
2. Выберите ваш проект
3. Settings → Environment Variables
4. Добавьте:
   - `TELEGRAM_BOT_TOKEN` = ваш токен
   - `TELEGRAM_CHAT_ID` = ваш chat id
5. Пересоберите проект (Deployments → Redeploy)

## Решение проблем

### Бот не отправляет сообщения
- Проверьте, что токен правильный
- Проверьте, что бот добавлен в группу (если используете группу)
- Проверьте, что бот является администратором группы

### Ошибка "chat not found"
- Убедитесь, что Chat ID правильный
- Для групп убедитесь, что ID начинается с `-`
- Попробуйте отправить боту сообщение напрямую перед тестированием

### Сообщения не приходят в группу
- Бот должен быть администратором группы
- Проверьте права бота (должна быть включена отправка сообщений)
