# Total Lookas — Лендинг для B2B-мерча

Современный корпоративный сайт на Next.js 15 с TypeScript и Tailwind CSS.

## Технологии

- **Next.js 15** — React-фреймворк с App Router
- **TypeScript** — типизация
- **Tailwind CSS** — стилизация
- **Google Fonts** — шрифт Golos Text

## Структура проекта

```
TL-new/
├── app/
│   ├── layout.tsx          # Root layout с метаданными
│   ├── page.tsx            # Главная страница
│   ├── content.ts          # Весь контент сайта
│   └── globals.css         # Глобальные стили
├── components/
│   ├── ui/                 # Переиспользуемые UI компоненты
│   │   ├── Button.tsx
│   │   ├── Card.tsx
│   │   ├── Badge.tsx
│   │   └── Section.tsx
│   └── sections/           # Секции лендинга
│       ├── Hero.tsx
│       ├── Services.tsx
│       ├── Blanks.tsx
│       ├── Cases.tsx
│       ├── HowWeWork.tsx
│       ├── WhyUs.tsx
│       ├── FAQ.tsx
│       ├── CTA.tsx
│       └── Footer.tsx
└── public/                 # Статические файлы
```

## Дизайн-система

### Цвета
- **Background**: `#303030` — основной фон
- **Foreground**: `#f8f8f8` — основной текст
- **Accent**: `#2928F1` — акцентный цвет (кнопки, ссылки)

### Типографика
- **Шрифт**: Golos Text (400, 500, 600, 700)
- **Размеры**: адаптивная типографика через Tailwind

### Радиусы
- **brand**: `15px` — все карточки и кнопки

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Запуск продакшен-версии
npm run start
```

## Секции лендинга

1. **Hero** — главный экран с заголовком и CTA
2. **Services** — что мы делаем (6 направлений)
3. **Blanks** — готовые бланки/лекала (6 позиций)
4. **Cases** — кейсы клиентов (3 проекта)
5. **How We Work** — процесс работы (4 шага)
6. **Why Us** — преимущества (6 пунктов)
7. **FAQ** — частые вопросы (8 вопросов)
8. **CTA** — форма обратной связи
9. **Footer** — контакты и реквизиты

## Редактирование контента

Весь контент находится в файле `app/content.ts`.  
Для изменения текстов редактируйте этот файл — компоненты автоматически обновятся.

### Конфигурация переменных

```typescript
export const CONFIG = {
  lead_time_min_days: 7,    // Минимальный срок
  moq: 30,                  // Минимальный тираж
  max_qty: 10000,           // Максимальный тираж
}
```

Эти переменные используются по всему сайту.

## SEO

Метаданные настроены в `app/layout.tsx`:
- Title и Description для поисковых систем
- Open Graph теги для соцсетей
- Язык страницы: русский (ru_RU)

## Адаптивность

Сайт полностью адаптивен:
- **Mobile**: < 768px
- **Tablet**: 768px — 1024px
- **Desktop**: > 1024px

## Производительность

- Server Components по умолчанию
- Client Components только где нужна интерактивность ('use client')
- Оптимизация шрифтов через next/font
- CSS-in-JS отсутствует — только Tailwind
