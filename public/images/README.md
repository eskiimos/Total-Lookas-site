# 📸 Инструкция по загрузке изображений

## 📂 Структура папок

```
public/images/
├── hero/               # Изображения для главной секции
├── blanks/            # Фото готовых изделий (бланков)
├── cases/             # Фото кейсов/проектов
├── logo.png           # Логотип компании (рекомендуется PNG с прозрачностью)
└── favicon.ico        # Фавикон для браузера
```

## 🎯 Какие изображения нужны

### 1️⃣ Логотип и фавикон
- **logo.png** — Логотип компании (рекомендуемый размер: 200×60 px, PNG с прозрачностью)
- **favicon.ico** — Фавикон 32×32 px или 16×16 px
- **apple-touch-icon.png** — Иконка для iOS 180×180 px
- **icon-192.png** и **icon-512.png** — Для PWA

### 2️⃣ Hero секция (public/images/hero/)
Опционально — можно добавить фоновое изображение или декоративные элементы:
- **hero-bg.jpg** — Фоновое изображение (1920×1080 px)
- **hero-decoration.png** — Декоративные элементы

### 3️⃣ Бланки/Изделия (public/images/blanks/)
Фотографии готовых изделий. Нужно **6 изображений**:

1. **tshirt.jpg** — Футболка унисекс
2. **hoodie.jpg** — Худи oversize
3. **polo.jpg** — Поло
4. **apron.jpg** — Фартук бариста
5. **totebag.jpg** — Тотебэг 30×40
6. **pyjama.jpg** — Пижамный комплект

**Рекомендуемые параметры:**
- Формат: JPG или PNG
- Размер: 800×800 px (квадрат) или 800×1000 px (портрет)
- Качество: 80-90%
- Фон: желательно светлый или прозрачный

### 4️⃣ Кейсы (public/images/cases/)
Фотографии реализованных проектов. Нужно **3 изображения**:

1. **case-1.jpg** — Digital-стартап (welcome-наборы)
2. **case-2.jpg** — Фестиваль (мерч для продажи)
3. **case-3.jpg** — Кофейня (униформа)

**Рекомендуемые параметры:**
- Формат: JPG или PNG
- Размер: 1200×800 px (горизонтальный)
- Качество: 80-90%

## 🔧 Оптимизация изображений

### Онлайн-инструменты:
- [TinyPNG](https://tinypng.com/) — сжатие PNG и JPG
- [Squoosh](https://squoosh.app/) — продвинутое сжатие
- [ImageOptim](https://imageoptim.com/) — для macOS

### Рекомендуемые форматы:
- **WebP** — современный формат с лучшим сжатием
- **JPG** — для фотографий
- **PNG** — для изображений с прозрачностью

## 🎨 Советы по фотографиям

1. **Единый стиль** — используйте похожие фоны и освещение
2. **Высокое разрешение** — фото должны быть четкими
3. **Продуктовая съемка** — показывайте изделия крупно
4. **Реальные кейсы** — лучше реальные фото, чем стоковые
5. **Брендирование** — показывайте логотипы на изделиях

## 🚀 После загрузки изображений

Изображения автоматически подтянутся в компоненты. Если нужно изменить пути или добавить alt-тексты, редактируйте соответствующие файлы:

- Бланки: `components/sections/Blanks.tsx`
- Кейсы: `components/sections/Cases.tsx`
- Hero: `components/sections/Hero.tsx`

## 📊 Проверка размера изображений

После загрузки всех изображений проверьте размер:

```bash
# В папке public/images
du -sh *
```

Общий размер всех изображений не должен превышать 5-10 МБ для быстрой загрузки сайта.
